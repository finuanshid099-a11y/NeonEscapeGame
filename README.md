# 🌃 Neon Escape

A cyberpunk-themed endless runner game built using Java Swing.

## 🎮 Features
- Jump and double jump
- Dash and slide
- Dodge obstacles
- Collect coins and earn points
- Neon graphics and visual effects

## ⌨️ Controls
- `SPACE / W / ↑` — Jump
- `SHIFT / X` — Dash
- `S / ↓` — Slide
- `P` — Pause
- `R` — Restart
- `ESC` — Return to menu

## 🚀 Run the Game

```bash
javac NeonEscapeGame.java
java NeonEscapeGame
